# 냥 패드 펫 · 계획서

## 만들 것
화면 오른쪽 아래에서 내 타자에 맞춰 게임패드를 두드리는 고양이 펫.

- 그림: `art/sheet.png` (2줄 2칸, 4장)
  - ① 왼쪽 위 · 만세 (두 손 듦)
  - ② 오른쪽 위 · 한 손 듦
  - ③ 왼쪽 아래 · 반대 손 듦
  - ④ 오른쪽 아래 · 손 내리고 눈 감음
- 움직임 규칙
  - 키를 1번 누를 때마다 ② ↔ ③ 번갈아 보여 줌
  - 1초 동안 6번 이상 누르면 ① 만세
  - 3초 동안 안 누르면 ④ 쉬기
- 위치와 크기: 오른쪽 아래, 작업표시줄 바로 위, 160×160. 다른 창보다 항상 위에 뜸
- 조작: 마우스로 끌면 옮겨짐, 오른쪽 클릭하면 "끄기" 메뉴
- 횟수: 펫 아래에 작게 표시 (예: `오늘 1,234`). 켠 뒤로 센 숫자이고, 끄면 사라짐

## 어디서 돌아가는지
- 내 컴퓨터: Windows 11, Python 3.15.0
- 마지막에는 `pet.exe` 하나로 묶어서 Python 없이도 더블클릭으로 실행

## 재료
| 할 일 | 재료 | 지금 상태 |
|---|---|---|
| 창 띄우기 | PySide6-Essentials | 설치 안 됨 |
| 키 듣기 | pynput | 설치 안 됨 |
| 그림 자르기 | Pillow | 설치 안 됨 |
| exe 로 묶기 | PyInstaller | 설치 안 됨 |

- 설치는 `week-03/.venv` (이번 주 전용 상자) 안에만 해서 다른 곳에 영향이 없게 한다.
- 설치하기 전에 꼭 물어본다.

## 단계

### 0단계 · 준비
- 할 일: 설치 허락 받기 → `.venv` 만들기 → 재료 4개 설치 → `requirements.txt` 와 `.gitignore` 만들기
- `.gitignore` 에 넣을 것: `art/`, `frames/`, `.venv/`, `build/`, `dist/`, `*.spec`
- 확인할 것
  - [ ] 재료 4개 설치 명령이 모두 오류 없이 끝났나요?
  - [ ] `.venv` 의 Python 으로 `import PySide6, pynput, PIL, PyInstaller` 를 실행하면 아무 오류 없이 끝나나요?
  - [ ] `git status` 결과에 `art/` 와 `.venv/` 가 안 보이나요?
  - 하나라도 "아니오"면: 멈추고 어떻게 할지 다시 정한다 (Python 3.15 에서 설치가 안 되는 재료가 있을 수 있음)
- 커밋: `week-03: 0단계 준비 (requirements, gitignore)`

### 1단계 · 그림 자르기
- 할 일: `cut_frames.py` 로 sheet.png 를 4장으로 자르고, 투명한 빈 곳을 다듬어 160×160 으로 맞춰 `frames/1.png` ~ `frames/4.png` 로 저장
- 확인할 것

  - [ ] 4장 모두 크기가 160×160 인가요?
  - [ ] `1.png` 가 만세, `2.png`·`3.png` 가 한 손 듦, `4.png` 가 눈 감음인가요?
  - [ ] 4장을 흰 바탕과 검은 바탕에 각각 올려 봤을 때, 고양이 둘레에 네모 배경이 안 보이나요?
  - [ ] 4장 모두 귀·무지개·패드 끝이 잘리지 않고 다 보이나요?
  - [ ] 4장을 차례로 넘겨 볼 때 패드 위치가 제자리에 있나요? (위아래·좌우로 튀지 않음)
- 커밋: `week-03: 1단계 그림 자르기` (`cut_frames.py` 만. 잘린 그림은 올리지 않음)

### 2단계 · 창 띄우기
- 할 일: `pet.py` 에서 테두리 없는 투명 창에 ④ 를 띄우기. 오른쪽 아래, 작업표시줄 위, 항상 위
- 확인할 것

  - [ ] 고양이 둘레에 네모 배경이나 창 테두리가 안 보이나요?
  - [ ] 메모장을 열어 펫 위로 겹치게 옮긴 뒤 메모장을 클릭해도 펫이 메모장 위에 보이나요?
  - [ ] 펫 아래쪽 끝이 작업표시줄 위에 있나요? (작업표시줄을 가리지 않음)
  - [ ] 작업표시줄에 펫 프로그램 버튼이 따로 생기지 않나요?
- 커밋: `week-03: 2단계 투명 창에 펫 띄우기`

### 3단계 · 옮기기와 끄기
- 할 일: 마우스로 끌어서 옮기기, 오른쪽 클릭 메뉴에 "끄기"
- 확인할 것

  - [ ] 마우스를 놓으면 그 자리에 그대로 있나요?
  - [ ] 고양이를 오른쪽 클릭하면 "끄기" 메뉴가 나오나요?
  - [ ] "끄기"를 누르면 고양이가 사라지나요?
  - [ ] 끈 뒤 작업 관리자(Ctrl+Shift+Esc)에 `python` 이 남아 있지 않나요?
- 커밋: `week-03: 3단계 끌기와 끄기 메뉴`

### 4단계 · 키 세기
- 할 일: pynput 으로 키가 눌렸다는 사실만 받아서 숫자 1을 더하고, 펫 아래에 `오늘 N` 으로 표시
- 확인할 것
  - [ ] 펫을 켜자마자 펫 아래에 `오늘 0` 이 보이나요?
  - [ ] 메모장에 `abcde` 다섯 글자를 치면 숫자가 정확히 5 오르나요?
  - [ ] 펫이 아닌 다른 창(메모장)에 입력하고 있을 때도 숫자가 오르나요?
  - [ ] 스페이스바를 5초 동안 꾹 누르고 있어도 펫이 멈추지 않고 끌기·끄기가 되나요?
  - [ ] `pet.py` 에서 키를 받는 부분이 키 값을 쓰지 않고 숫자에 1 더하기만 하나요? (Claude 가 그 부분을 보여 주고 같이 확인)
  - [ ] `pet.py` 에 `print`, `open(`, `write`, `requests`, `socket`, `urllib` 이 한 번도 안 나오나요?
  - [ ] 펫을 끄고 다시 켜면 숫자가 `오늘 0` 부터 시작하나요? (저장 안 됨)
- 커밋: `week-03: 4단계 키 횟수 세기`

### 5단계 · 타자에 맞춰 움직이기
- 할 일: 움직임 규칙 넣기 (키 1번마다 ②↔③, 1초에 6번 이상이면 ①, 3초 동안 없으면 ④)
- 확인할 것
  - [ ] 1초에 한 번씩 키를 누르면 누를 때마다 ② → ③ → ② → ③ 으로 바뀌나요?
  - [ ] 1초 동안 키를 6번 넘게 빨리 누르면 ① 만세가 나오나요?
  - [ ] 1초에 2~3번 정도로 치면 ① 만세가 안 나오나요?
  - [ ] 키에서 손을 떼고 3초가 지나면 ④ 로 바뀌나요?
  - [ ] 손을 떼고 1초 뒤에는 아직 ④ 가 아닌가요?
  - [ ] ④ 상태에서 키를 1번 누르면 바로 ② 나 ③ 으로 바뀌나요?
  - [ ] `pet.py` 맨 위에 `6` 과 `3` 이 이름 붙은 숫자로 따로 적혀 있나요?
- 커밋: `week-03: 5단계 타자에 맞춰 움직이기`

- 커밋: `week-03: 6단계 exe 로 묶기` (`build.bat` 만. exe 는 올리지 않음)

## 하지 말 것
- 어떤 키를 눌렀는지 저장·전송·출력하지 않는다. 파일, 인터넷, 화면, `print` 어디에도 남기지 않는다. 몇 번 눌렀는지만 센다.
- 누른 횟수도 파일에 저장하지 않는다. 끄면 사라진다.
- 펫은 인터넷에 연결하지 않는다.
- `art/sheet.png`, 잘린 그림, `pet.exe` 는 커밋하지 않는다 (다른 사람이 만든 캐릭터를 닮은 그림이고, 공개 저장소라서).
- 이번 주 규칙에 없는 재료를 쓰지 않는다. 새로 설치할 때는 먼저 물어본다.
- 앞 단계의 "확인할 것"이 모두 "예"가 되기 전에는 커밋하지 않고 다음 단계로 넘어가지 않는다.
- week-03 폴더 밖의 파일은 건드리지 않는다.
